The startup shell runs more on a file with 7 lines and immediately quit.
ssh inherits the terminal from my linux laptop. If we set the height of this terminal to say 6
lines, it forces the remote more to paginate.
While it's paginating, you can run vi on the current line (by pressing v) and 
from vi escape to shell.


tim@astrazeek:~$ stty rows 6 && ssh -p 2220 bandit26@bandit.labs.overthewire.org -i apps/overthewire/bandit26.sshkey
